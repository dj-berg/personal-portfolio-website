## Running Locally

Clone the repository:

```bash
git clone https://github.com/dj-berg/personal-portfolio-website.git
```

Open the project:

```bash
cd personal-portfolio-website
```

Launch:

```bash
index.html
```

or use the VS Code Live Server extension.
